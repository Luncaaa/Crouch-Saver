# Crouch Saver
Keep crouching when opening a GUI or crouch when opening one on a ladder!

Download from [Modrinth](https://modrinth.com/project/crouch-saver) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/crouch-saver)

This is a very simple and lightweight mod which does 2 things (can be toggled independently):
- Keep you crouched when opening a GUI (including chat) if you were previously crouching (without the mod you'll stop crouching even if holding shift when opening the GUI).
- Make you crouch if you open a GUI (including chat) while on a ladder.

This mod has no dependencies and its settings can be found inside Minecraft's Settings > Controls screen
